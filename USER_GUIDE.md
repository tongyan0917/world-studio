# World Studio creator guide

Start with `npm install && npm run studio`, then open
`http://127.0.0.1:4317`. Everything stays in the selected local SQLite file.

## Create a World

Open **Author**, choose **New template**, and edit or paste a Creator Definition
v1 JSON document. **Inspect premises** turns consequential omissions into direct
questions. Once it reports ready, **Save draft** and **Compile & accept** create
an immutable Contract and Instance. The editor covers time, geography/routes,
populations, people, organizations, institutions, resources, relationships,
information, hazards, conditional Theory Packs, hard rules, parameters, initial
facts, and optional extensions; no TypeScript edits are required.

## Explore and document

**Explore** switches among typed objects, relationships, graph, inspector, and
map. A location states whether its coordinates are creator-authored or merely a
non-causal layout; image references are optional and never become state
authority. **Wiki** stores Markdown pages, `[[Page title]]` links, backlinks,
tags, and search inside the current World.

## Evolve and pause

Open **Evolve**, enter a seed, and start. **Advance boundary** commits one whole
macro/meso/micro boundary. **Pause safely** stops before the next boundary;
**Resume** continues from the exact persisted prefix. **Run to complete** closes
the remaining installed dimensions and feedback families. A completed Run shows
its closure, hashes, and provenance.

## Branch and explain

Open **History Lab**, select an object, attribute, and any World time. An
**Intervention** is a typed external input that still passes Contract/Kernel
validation. A **Soft directional prompt** records search guidance but guarantees
nothing and commits no state directly. The result keeps the exact causal prefix
and separates changed domain state, audit noise, forward impact, backward
explanation, initial roots, model provenance, and unresolved uncertainty.

## Export

Select a completed Run or branch and click **Export setting book**. The Markdown
download contains readable setting sections, history, unresolved uncertainty,
and a Contract/Run/state/trace provenance manifest. Export and Wiki edits are
projections: neither can mutate the World.
